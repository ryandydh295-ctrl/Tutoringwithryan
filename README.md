## 🎮 How to Play

- **Click the candy** to earn candy (starts at +1 per click).
- **Buy buildings** on the right to earn candy automatically every second.
- **Buy upgrades** to boost your click power and CPS.
- **Golden candies** occasionally appear on screen — click them fast for bonuses!
- Try naming yourself `candyhacker3000` in Settings... 👀

## ✨ Features

- 🍭 12 buildings with unique passive bonuses
- ⬆️ 30+ upgrades (click power, CPS multipliers, special effects)
- 🍭 Golden candies with Lucky / Frenzy / Dragonflight rewards
- 🎨 5 themes (Candy, Mint, Galaxy, Sunset, Midnight)
- 👤 Custom player name
- 💀 Hidden hack menu
- 💾 Auto-save (localStorage)

## 🛠️ Built With

- Plain HTML, CSS, and JavaScript — no frameworks, no build step.
- Single file. Just open `index.html` in a browser.
